# SkillSpring — Online Learning Platform Landing Page

## Project Overview

SkillSpring is a fictional online learning platform designed to help students and beginners develop new skills through online courses. This project is a responsive landing page concept designed in Figma to provide a modern, attractive, and user-friendly learning experience.

## Target Audience

- College students
- Beginners interested in learning new skills
- Working professionals
- People interested in online education

## Design Goals

- Create a clean, modern, and attractive visual identity.
- Make learning opportunities and courses easy to discover.
- Provide simple and user-friendly navigation.
- Maintain consistent spacing, typography, and colors.
- Adapt the layout for desktop and mobile screens.

## Design System

### Color Palette

- Primary: Lime Green
- Background: Light Cream
- Secondary: Light Green
- Text: Dark Charcoal
- Cards: White and pastel colors

### Typography

- Headings: Bold modern typography
- Body Text: Clean and readable sans-serif typography

### Visual Style

Minimal, modern, creative, and student-friendly design with generous whitespace, rounded cards, attractive illustrations, and a fresh educational theme.

## Page Sections

1. **Header:** Brand logo, navigation links, and Get Started button.
2. **Hero Section:** Main headline, supporting text, learning message, and call-to-action buttons.
3. **Features Section:** Information about the platform's learning benefits.
4. **Learning Benefits:** Features that help students grow their skills.
5. **Popular Courses:** Course cards with descriptions and prices.
6. **Student Learning Experience:** Information about learning opportunities.
7. **Call-to-Action Section:** Encouraging students to start learning.
8. **Footer:** Useful links and platform information.

## Reusable Figma Components

- Header / Navigation
- Primary and Secondary Buttons
- Course Cards
- Feature Cards
- Learning Information Cards
- Footer Links

Components are reused consistently throughout the design to maintain a uniform visual experience.

## Responsive Layouts

The design includes:

- Desktop Layout
- Mobile Layout

The layout adapts to smaller screens by stacking content, adjusting grids and spacing, keeping text readable, and ensuring buttons are easy to use.

## Figma Techniques

- Auto Layout for headers, buttons, cards, and content sections
- Reusable components and variants
- Shared color and typography styles
- Consistent spacing
- Clear layer, frame, and component naming

## Tools Used

- Figma
- Figma Auto Layout
- Figma Components
- Figma Variants

## Note

SkillSpring is a fictional online learning platform created for a UI/UX design assignment. Course information and platform details are illustrative.
